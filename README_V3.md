# Portfolio V3 — Interactive IT + AI Experience

This branch contains Michael Harris's rebuilt interactive portfolio.

## Included

- Custom animated visual system inspired by Michael's original HARRIS identity
- Real AI chatbot frontend and secure `/api/chat` backend
- Grounded recruiter-focused AI profile
- Conversation memory within the browser session
- Interactive network troubleshooting simulator
- Interactive SQL ticket explorer
- XML workflow inspector
- Project, experience, résumé, GitHub, LinkedIn, and contact sections
- Responsive mobile layout and reduced-motion support

## Review branch

`portfolio-v3-real-ai`

The branch is intentionally separate from `main` so it can be previewed and tested before replacing the live site.
